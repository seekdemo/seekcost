# SeekCost 界面规范

全站视觉入口：`frontend/src/app/visual-system.css`，在根布局中加载。

- 页面使用 `PageShell` / `.page-header` / `.page-title` / `.page-description`。标题桌面 28px、手机 23px；模块标题通常 18px。文章正文保留阅读层级。
- 卡片使用 `Surface` / `.ui-surface`：10px 圆角、主题边框、轻阴影。对话框 14px 圆角。
- 操作使用 `.ui-button`，主操作加 `.ui-button--primary`；7px 圆角、桌面至少 40px、手机至少 44px 高度。圆形头像、颜色选择器不按矩形按钮处理。
- 表单优先 `.field-label` / `.field-input`，手机文本输入 16px，避免聚焦放大。所有可交互元素保留可见焦点。
- 色彩使用主题变量，不硬编码白底或深色文字。绿/蓝/黄/红用于机会、观察、延伸、风险；行情涨跌配色独立保留。
- 用户选定的封面颜色与图片保留；六位十六进制封面颜色按相对亮度选择黑/白文字。无自定义颜色时使用中性主题色。
- 不用放大阴影、装饰渐变或卡片上浮强调普通模块；未读、风险和选中状态仍须明确表达。
- 新页面验证 1440px、834px、390px，至少抽查深浅主题；截图等待数据加载，不把骨架屏当成成品。

回归：`e2e/platform-visual-system.spec.ts`。登录后的只读巡检需显式提供 `SEEKCOST_E2E_TOKEN`；后台写入流程只在 API mock 测试中验证。

## 精细排版补充

- 间距使用 4/8/12/16/20/24/32px 刻度。普通页面的导航与内容共享 1440px 外框；正文、设置等阅读型页面保留较窄宽度。
- 浅色采用浅灰画布与白色内容面板，不再让所有模块混在同一白底上。取消页面背景光晕。
- 研究卡片默认三列、平板两列、手机单列；标题只出现一次。自定义纯色封面保留为 56px 状态条，真实图片保留图像区域。正文摘要与底部操作单独对齐。
- 研究阅读页使用独立文稿面板，桌面内边距 32px、手机 20px。文章标题、元信息、正文对齐的是面板内容边界，不是外边框。
- 手机股票池使用自然页面滚动，避免在页面内再嵌套一个 68vh 的滚动区域。
- 标的详情先显示 K 线与风险，再提供研究入口。看板及日 K 的价格统一两位小数；行情组件自身的市场精度保持不变。
- 默认空状态用文档轮廓，不使用可能误解为“操作成功”的勾号。删除确认使用白字红底，不继承主题主按钮文字色。
