# 自定义量化提醒：第一版

## 使用方式

1. 打开「决策 → 自定义提醒」，或访问 http://localhost:3000/alerts。
2. 点击「新建提醒」，输入名称，选择检测范围「单只股票」或「全部自选股」，设置 SMA 周期、偏离百分比、方向及冷却时间。「全部」是当前账户的股票池，不是全市场；新增股票自动纳入，每只股票独立触发和冷却。股票池为空时也可以预先保存全量规则。
3. 默认示例为 SMA 20、上下 2%、冷却 24 小时。周期支持 2–250 个交易日，偏离范围 0.1–20%，同一只股票可有多条规则，每个账户最多 100 条。
4. 保存并启用后，下一个后台检测周期生效。规则卡可编辑、暂停、恢复或删除；删除规则保留历史通知。
5. 导航铃铛显示未读数量，点击进入通知中心。支持全部/未读筛选、标记已读、全部已读、加载历史及查看股票。

## 检测语义

- 后台每轮扫描后等待 5 分钟；首次启动等待 10 秒。无规则时不会请求行情。无需保持网页打开，但后端服务必须运行；本机休眠或服务停止时不检测。
- 最新有效价格来自 Yahoo 常规交易时段 5 分钟采样，非实时。行情时间超过 20 分钟、缺少交易时段、非正常交易时段、历史不完整或供应商失败时不触发。
- SMA 取最近 N 个已完成日线收盘价，复用日线完成判定（本地交易日 16:15 前排除当日日线）；偏离 = (价格 / SMA − 1) × 100%。该保守完成口径可能延后计入收盘日线。
- 双向为 [−阈值, +阈值]；上方为 [0, +阈值]；下方为 [−阈值, 0]，包含边界。
- 首次有效检测在范围内会提醒。持续在范围内不重复；有效离开后再次进入才重新提醒。
- 冷却期间的再进入被抑制，不在冷却结束后补发。必须再次离开并进入。编辑条件/重新启用会重新检测，但保留之前的冷却时间起点。
- 数据异常不改变进入/离开状态，防止恢复行情后重复轰炸。状态、最近检测时间、最近有效偏离均可在规则卡查看。
- 通知保存规则名称、代码、SMA 周期/范围、触发价格、均线、偏离、行情时间、均线截至日期与来源，不随后续编辑或行情变化。
- 本版没有邮件、微信、系统/浏览器推送，也不执行交易。采样间短暂穿越可能被遗漏。

## 实现与数据安全

- `custom_alert_rules` 和 `alert_notifications` 为独立的新表，不改写旧社交通知表。
- 全部 API 使用已有登录校验及账户过滤。股票归属在创建/编辑时校验，规则/通知跨用户访问拒绝。
- 状态变更使用 version compare-and-swap，通知插入与状态更新在同一事务中。扫描期间规则/标的变更会跳过旧结果。
- 扫描按 symbol/market 共享行情，最多 4 组并发；单条失败不停止其他规则。
- 本地 SQLite 通过现有启动初始化增量建表；其他部署提供 Alembic `e5a9b1c4d7f0` 迁移。迁移升/降级仅在隔离测试数据库验证，未对用户数据库执行降级。
- 删除自选股同时删除其单股规则及对应检测状态，全量规则保留，解除历史通知链接但保留通知；演示账户清理路径已纳入新表。

## 全部自选股扩展（2026-09-18）

- 新建和编辑都支持范围切换。全量规则显示覆盖数量、已检测数量、范围内和暂不可用数量。数量反映最近一次各标的检测状态，不代表行情实时可用。
- 新增 `custom_alert_rule_states` 保存每条规则、每只股票的独立进入/离开状态和冷却时间。首次在范围内可产生多只股票的独立通知；持续停留不重复。
- 切换范围和修改条件会重新检测，已有标的冷却起点保留。暂停/编辑导致父规则版本变更，扫描中的旧结果不会生效。
- Alembic 新迁移 `f6b0c2d5e8a1` 将旧规则保留为 `single`，允许全量规则的 `stock_id` 为空。存在全量规则时拒绝有损降级。
- 本地 SQLite 启动时执行等价的幂等结构升级。升级前备份位于 `/tmp/seekcost-alert-scope.CFDBCG/before.sqlite`；临时目录备份不作为长期备份。未更改用户现有规则或创建测试通知。
- 前端 15 项 Chromium 响应式测试通过（1440/834/390px），包含空股票池、范围切换、全量保存、原单股流程和真实账户只读检查；真实表单显示 191 只标的。TypeScript 和 Webpack 生产构建通过。
- 后端隔离数据库测试覆盖独立触发、新增标的纳入、账户隔离、暂停、版本竞争、范围切换、删除保留通知、空股票池、旧结构升级及迁移降级保护。截图位于 `frontend/test-results/custom-alerts-*`。
