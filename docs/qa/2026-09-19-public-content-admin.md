# About 与公共内容管理员后台

## 用户可见变化

- `/about` 新增开发者第一人称的开发初衷、平台价值与未来优化方向。未来计划明确标记，不承诺已经上线或具体交付日期。
- 中文与英文主内容由公开 API 读取；匿名用户可访问，不会收到草稿。其他界面语言使用英文文案。
- 现有隐私、行情边界、非投资建议声明和使用指南链接保留为固定平台说明；第一版后台管理 About 主内容，不管理这些固定说明或 Guide 正文。

## 后台使用

1. 使用获授权账户登录，打开 `/admin`；管理员也能在 About / Guide 顶部看到「内容管理」。
2. 选择简体中文或 English，修改标题、导语、开发初衷、平台价值和未来方向。空行分段，纯文本安全渲染，不执行 HTML。
3. 点击「保存草稿」，此时公开内容不会改变。失败时输入保留。
4. 点击「页面预览」核对。只有保存后且草稿与公开内容不同时，才可点击「发布内容」。
5. 确认发布后，访客刷新或重新打开 About 可看到该语言的新版本。
6. 操作记录展示最近 50 次保存、发布及权限操作。这不是历史内容版本库，不提供一键回滚；需要恢复时重新编辑、保存、发布。

## 管理员初始化与撤销

没有默认管理员，没有公开的授予权限 API，也不会把首个注册用户或演示用户自动提升。先由平台所有者明确指定已注册账户，再由可信服务器维护者执行：

```sh
cd /path/to/user/Desktop/SeekCost/backend
.venv/bin/python -m app.core.site_admin grant ACTUAL_USERNAME
```

撤销用相同命令，将 `grant` 改为 `revoke`。用户名必须替换为已确认的实际账户。命令幂等，找不到账户直接失败，不创建账户或密码。使用现有环境的数据库配置。每个管理请求会重新查数据库权限，撤销后已有登录令牌也不能继续访问后台。

角色为公共内容管理员，不额外赋予查看其他账户研究、持仓、交易的权限。注册和个人资料接口不能授予该角色。操作依赖现有登录认证；上线到公网仍需按部署要求启用 HTTPS、保护服务器和数据库权限，不应复用演示密码。

## 数据与迁移

- 新表：`site_admins`、`site_content`、`content_audit`，没有修改现有用户字段。
- 本地 SQLite 沿用启动时 create_all 增量建表；Alembic 部署使用新增 `a7c1d3e6f9b2` 迁移。
- 无数据库内容时公开接口返回初始文案；第一次保存创建独立草稿。发布记录与版本变更在同一事务，旧版本提交返回 409，防止覆盖他人更新。
- 账户清理撤销权限并解除审计的账户引用，不删除公共内容与审计历史。
- 迁移降级在含有权限、内容或审计数据时拒绝执行，避免静默数据丢失。
