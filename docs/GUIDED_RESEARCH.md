# 公司研究室 · 第一版

入口：研究资料库中的「公司研究室」，或任意候选公司详情顶部。直接访问 `/research/guide`。

核心不是给用户分级，而是帮助每个人理解公司：生意怎样运作、客户为什么选择它、经营和现金流是否一致、反面证据是什么、价格包含哪些假设，以及什么会改变自己的判断。

## 两种工作方式

- **引导研究**：一次处理一个问题，可展开通俗解释，也可以暂时不知道或跳过。问题导航允许直接跳到感兴趣的部分。
- **自主研究**：以研究目录呈现全部问题，按需展开任意章节，也可以同时打开多个章节。解释默认折叠，不强制完成教程。

两种方式共用同一份记录，可随时切换；选择随公司草稿一起保存，不按能力给用户贴标签。

## 保存和继续

先将公司加入自己的股票池，再打开研究室。内容通过「保存进度」「保存并继续」或问题导航保存到当前账号，并非逐字自动保存。未保存时会显示提示，离开链接或关闭页面会提醒。保存失败保留当前文字；多窗口版本冲突不会静默覆盖，可下载 JSON 草稿保留文字后重新加载（第一版不提供 JSON 自动导入）。

手机端用「研究问题」下拉菜单切换问题或打开判断卡；编辑时收起网站的二级导航和底部导航，返回公司列表后恢复。输入区下方提供疑问、证据、研究提示三个折叠入口，避免同时堆叠长表单。保存操作位于编辑内容之后，不悬浮遮挡输入。

每个问题可以记录自己的理解、当前状态、待验证或反面理由、最多 8 条证据。证据支持名称、HTTP(S) 链接、相关摘录和财报期间／口径。已有公司档案的资料可手动引用，但仍属于个人记录，并非平台核实的数据。

「我的判断卡」先预览，再勾选确认。确认后保存为私有研究笔记并关联公司，空白和未知不会被系统补写。相同草稿版本重复确认不会产生重复卡片；新版本确认会新增快照，不覆盖以前的判断。删除公司后已保存笔记仍保留。

## 明确边界

- 思考提示是根据记录状态选择的人工编写模板，不是 AI 对公司或用户能力的评判。
- 不自动获取或解析财报，不自动生成财务趋势、目标价和推荐；资料和数据需要用户自行核实。
- 不会根据「已记录想法」推断观点已被验证，研究进度不是能力或投资价值评分。
- 目前是中文体验；没有自动研究分流、推荐画像、投资逻辑变化提醒或高级估值引擎。
- 同一账号下记录可跨设备继续；公开 demo 是共享账号，不适合保存真实私人研究。

后续应先验证两种方式是否真正帮助用户形成有证据的理解，再加入可靠的财报数据、行业模板和假设更新提醒。

## 运维与验证

生产 PostgreSQL 使用 Alembic 升级新增 `research_guides` 表；本地 SQLite 开发模式在后端启动时创建新表。先备份，后升级。不删除既有表或记录。

后端测试：`cd backend && .venv/bin/python -m pytest tests/test_research_guide.py -q`。

浏览器测试：前端服务运行时，在 frontend 执行 `npx playwright test e2e/guided-research.spec.ts`。浏览器测试使用拦截的虚构数据，不写入真实账号。
